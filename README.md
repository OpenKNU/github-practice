# Github Practice

GitHub 저장소의 기본 구조와 오픈소스 기여 과정을 실습하는 저장소입니다.

## 실습 목표

- 저장소 Fork 및 Clone
- 작업 브랜치 생성
- 자기소개 Markdown 파일 작성
- Commit 및 Push
- Pull Request 생성

## 작업물

`participants` 폴더에 자신의 GitHub ID를 파일명으로 사용해 Markdown 파일을 추가합니다.

```
participants/<github-id>.md
```
